# 项目覆盖端口

此目录优先于共享 `scripts/vcpkg/ports`，只承载当前应用必须使用、共享端口尚未包含的修复。

`talcs` 保留共享端口的 `v0.1.0` 配方及 ASIO 路径辅助文件，增加两项音频位置修复：

- 循环跨回绕点后使用剩余读取长度推进 transport，避免下一音频块跳过已经多计的位置。
- 切换预读模式时停止预读并恢复当前位置；直接读取时同步推进位置，避免离线导出的起点
  取决于后台预读进度，或重新启用预读后重复已读音频。

`rtmidi` 保留上游 `6.0.0` 配方，修正 CoreMIDI 客户端创建函数错误的 `throw()` 声明，
让驱动初始化失败传到调用方已有的异常处理，而不触发 `std::terminate`；客户端名称在
检查创建结果前释放，避免失败返回时泄漏。输入和输出共用同一修复语义。
应用 manifest 在 Linux 显式请求 `alsa` 特性，Windows 和 macOS 使用各自的原生后端。

vcpkg 覆盖端口需要完整配方，因此在此保留原有依赖和构建选项；每个库仍只链接一份。

共享或上游端口包含等价修复并经应用回归验证后，移除对应覆盖配方；目录为空时同时移除
manifest 中的项目覆盖路径。
