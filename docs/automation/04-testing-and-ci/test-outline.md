# 四期测试大纲

## 1. 组织原则

测试按产品行为组织，六类表示验证职责，不与程序逐项对应。同一行为在领域层验证规则，在接口层验证转换与授权，在进程层验证产品装配。真实 GUI 输入及可见结果由界面层负责。

新增行为归入已有 Qt Test slot 或数据行。一个程序保持一个测试类和一次 qExec，CTest 管理程序运行条件。用例采用 `tst_<snake_case>.cpp`，多文件套件使用 test_main.cpp 和相应声明头。fixture 在用例边界复位，失败断言保留实际值和调用位置。

工程内容比较复用生产 DSPX 内存编码。对象身份、revision、dirty/savepoint、撤销入口和非持久化状态另行检查，不能用对象数量或局部快照替代完整工程保真。

## 2. 基础数据与算法（unit）

- 音乐时间、小节/tick/time、速度与拍号投影、量化和音频时间锚点。
- 曲线插值、重采样、描摹、裁剪、变换、锚点布局及音高显示策略。
- 声线继承、固定与动态混合、分段权重插值、推理输入转换、会话缓存及失效。
- 歌词拆分、分行、LRC 时间与重载、规则优先级、词典、音节及文字属性级联。
- 本地化文本、配置读写、Provider 编译条件、CLI、自有数据结构、日志和单例注册。
- 任务完成发布、取消竞态与后续队列接续。使用受控时序，不依赖偶发调度。

## 3. 编辑与应用状态（domain）

- 轨道排序，歌声和音频片段复制、移动、裁边，音符创建、移动、量化、切分、搜索和删除。
- 歌词、语言、手工读音、候选、音素名称及时间偏移的修改、重置和关联清理。
- 绘制/锚点曲线的局部修改、整组替换、插入、合并、描摹及变换。检查几何、值域、拓扑、范围外保留和批量拒绝。
- 轨道与片段的声音上下文、继承、预设、固定/动态混合、关键帧身份、首帧保护及模式切换。
- 速度、拍号、主输出、持久循环、选择和活动对象。区分文档修改与瞬时界面状态。
- 剪贴板保留全部参数层、音符范围外内容、音频来源和相对位置。损坏数据按入口契约整批拒绝或舍弃受损组。
- 预验证、no-op、显式幂等、一次提交、撤销重做、dirty/savepoint、revision 和文档换代。
- 应用设置、歌词规则、包和预设的服务契约。失败恢复保持配置、运行时及用户历史一致。

## 4. 文档、文件与异步工作流（workflow）

- 新建、打开、保存、另存、最近工程、关闭和退出。验证保存决策、路径与覆盖策略、保存点、取消及失败后的继续操作。
- DSPX 完整内容往返，MIDI 时间、歌词及可选时间线元数据，菜单导入、编码/通道重解析和批量混合导入。
- 外部转换器的进程参数、失败、取消和输出接线。仅替换外部进程，生产解析器和文档提交继续执行。
- 音频路径查找、摘要、来源目录、重定位、确认、解码和来源代际。保存、粘贴、撤销及搬迁后仍可恢复素材。
- 文件快照、准备、发布及清理。验证原子模式和尽力模式、授权撤销、文档冲突、目标删除、取消和幂等重试。
- 真实混音、WAV/FLAC/Vorbis/MP3 导出、采样格式、增益/声像/静音、分轨命名、削波、覆盖及取消。输出重新解码，离线操作恢复混音器原状态。
- 推理的准入、阶段重置、等待编辑、结果 Apply/Drop/Defer、缓存复用与损坏恢复、取消、重启和替换。晚到结果不得落入旧文档或已删除对象。
- 真实语言任务的暂存与写回，混合语言结果对齐，服务失败后的清理，手动声学许可及播放窗口调度。
- 声库扫描、诊断、版本刷新、目录拒绝发布和会话初始化/退出。资源套件执行真实加载、各阶段推理、声码器及 WAV 输出。
- 音高/MIDI 提取的公共准备、来源完整性、权限、取消、结果过滤、目的地、历史和重试。GAME/RMVPE 实际模型保留约定边界。

## 5. 接口与 Connector（protocol）

- Native JSON-RPC、MCP、HTTP、stdio 的信封、分帧、结果和错误传递，运行时 JSON 校验器的值语义及诊断路径。
- 权限、文件访问、Host 能力、准入、任务类型、公开取消与终态资源释放。
- 工程和声库分页、游标失效、版本/本地化投影、参数范围及输出预算，读取不得修改工程。
- 代表性编辑、填词、声线、时间线、设置、音频和文件工作流经过公开 Registry，检查参数转换、业务结果及副作用。共享历史回放，不复制领域边界矩阵。
- 导入计划在执行前复验来源和授权。音频路径更新在提交前再次验证读取权限。
- Connector 握手、目录分页、权限/宿主刷新、重连、会话失效和离线状态。失败不能发布部分目录或转发不允许的业务调用。
- 超时、背压、EOF、损坏/错配/截断响应和 outcome_unknown。已送达的命令不隐式重试。
- HTTP 停止与路由禁用、完整退出响应、共同排空期限及同端口恢复。stdio 断管经可诊断错误退出。

不维护工具数量、工具清单或字段 Schema 镜像。

## 6. 真实应用进程（process）

- 启动实际 Editor 和 Connector，覆盖 GUI Host、Headless、Native/MCP 装配及代表性编辑、保存、重开和音频导出。
- 单实例身份、启动连接、转发与 ACK、端口冲突、错误退出、重启及当前平台终止信号。
- 生命周期验证实际退出状态、进程所有权、数据目录及资源释放。资源客户端共用正式协议传输。
- 模型装配由 ModelResources 承担。普通进程流程使用 CPU 和小型素材，资源条件不会成为全部进程测试的前提。

## 7. 界面组件与交互（gui）

| 界面职责 | 覆盖内容 |
|---|---|
| 编辑输入 | 钢琴窗、轨道和参数的绘制、选择、拖动、裁边、切分、擦除、Shape/Scale/Modulate、锚点和动态声线。验证预览、取消、单次提交、完整撤销及命中恢复 |
| 指针归属 | 鼠标、合成触控和笔事件，单指导航、双指接管、长按、系统取消、窗口失活、内联文本接管、工具恢复及边缘自动滚动 |
| 文字与声音 | 歌词/发音内联编辑、音素对话框和边界、搜索、填词预览和规则、声线菜单/混合/预设、推理诊断角标及原因 |
| 文档与文件 | 真实菜单、Qt 文件选择、拖入、导入配置、导出预演/执行/进度、缺失素材确认和重定位。保存决策状态机中使用外部回答替身的部分单列为工作流 |
| 工作区 | 主窗口面板、焦点、快捷键、历史定位、滚动条、视口与动画、零长度唱段恢复、分离/重嵌入及关闭后的继续编辑 |
| 设置与反馈 | 即时保存、写入失败恢复、延期重启、异步 GPU 枚举、音频/MIDI 配置、主题及语言切换、日志、工具提示、数值控件和电平反馈 |
| 渲染 | Legacy 与 RHI 各自的输入接线、主题、几何、字形/图标、波形、实际帧、上下文切换及后端失败回退 |

普通控件使用 offscreen，Qt QDrag 套件使用 minimal，原生窗口在 Linux Xvfb 或当前系统桌面运行。默认 Legacy/QGraphicsView 和实验 RHI 分别验证实际接线。RHI 的 Null 后端验证 CPU 准备与帧提交，平台后端数据行使用 Windows D3D11 软件渲染、macOS Metal 或 Linux OpenGL，读回同次运行的小区域验证绘制与撤销，不建立跨平台截图基线。

后端可用后的绘制、读回、事件或断言失败必须失败。真实驱动的笔悬停、全部窗口管理器、多屏、GPU 组合和主观观感不由合成事件或 Null 后端证明。

## 8. 资源与平台边界

内置微型声库以独立身份提供中英文、两条声线和各推理阶段的确定性计算图，默认执行真实包加载、语言处理、CPU 推理与文件输出。可显式换用真实声库。资源细节见[素材说明](../../../src/tests/resources/README.md)，配置方式见[执行计划](test-plan.md#3-运行条件)。

音频设备自动探测或按名称选择，使用静音素材验证实际回调、配置和播放。MIDI 使用显式配置的专用回环。GPU 按已编译 Provider 和实际设备执行。缺少条件的具体用例报告 QSKIP，已配置资源的加载或执行失败报告 FAIL，不跳过整个套件。

GAME/RMVPE 实际模型、主观听感和硬件组合不在本期扩展范围。CI 三平台执行全部适用测试，只有 Linux 在独立步骤生成覆盖率。Windows/MSVC 和 macOS/LLVM 的本地采集入口保留。

## 10. 业务逻辑覆盖统计边界

原始行覆盖保留完整生产源码范围。业务逻辑统计根据源码职责单独记录排除范围，同一规则处理已覆盖和未覆盖行。未完成分类的范围继续纳入。普通错误处理、异步提交、配置持久化、GUI 输入接线、活动 Legacy 和 RHI 实现均纳入，条件资源缺失不直接缩小范围。逐文件区间及计数保存在覆盖产物，统计方法见[测试报告](test-report.md#51-统计口径)。

| 范围 | 分类依据 | 保留在测试与统计中的相关逻辑 |
|---|---|---|
| 公共工具的 Schema 构造函数 | 声明输入输出定义，不按字段、工具数量或完整清单镜像补测 | 运行时 JSON 校验、参数转换、路由、授权及业务结果 |
| Qt 元对象、类型与私有指针声明、类声明、显式默认成员 | 元信息或生成的指针转换不含手写业务行为 | 手写方法、信号调用及声明所关联的实际行为 |
| 固定数值的界面边距和间距设置 | 只声明布局尺寸，没有计算或业务副作用 | 条件选择、计算几何、可见性、事件接线和设置持久化 |
| EventDiagFilter 与 RHI 的性能统计输出 | 开发者性能采样、聚合与日志格式，不影响工程、编辑或任务结果 | 事件传递、过滤器生命周期与开关持久化，RHI 帧生成、重绘、资源及失败处理 |
| GAME/RMVPE 模型执行 | 本期约定不执行实际模型 | 通用准备、文件快照、来源校验、准入、取消及失败恢复 |
| SeekBar、TaskWindow、G2pListWidget、G2pInfoWidget、GraphicsLayerManager、DirSelector、AcrylicBrush 的旧实现 | 已确认没有当前产品创建或调用路径，暂时保留 | 当前实际使用的控件、歌词和发音界面、图层与绘制逻辑 |
| PianoKeyboardView 的 Uniform 专属分支及未调用绘制、坐标助手 | 当前键盘固定为 Classic，没有样式修改入口，sceneYToKeyIndex 仅由 Uniform 输入分支调用 | Classic 绘制与 posToKeyIndex 输入、主题属性、滑奏及音符释放 |
| ProgressIndicator 的 Ring 专属绘制和尺寸分支 | 产品导出窗口使用 HorizontalBar，没有 Ring 选择入口 | 导出进度、横向绘制、动画、状态与主题 |
| Registry 的旧富草稿解码、未调用私有解码及 Editor 旧能力查询包装 | 封闭草稿 Schema 拒绝旧字段，其他旧包装经调用点检查确认没有当前入口，暂时保留 | 当前草稿默认值、音频导入、公开编辑与能力查询、声线及混合解析，运行时校验 |
