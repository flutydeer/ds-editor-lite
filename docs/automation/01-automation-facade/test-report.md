## 勘误 01：轮次 01～02 的配置隔离

Windows 下 Qt 的 `QStandardPaths` 未因仅设置 `APPDATA/LOCALAPPDATA` 环境变量而重定向。
后续日志证明轮次 01～02 实际仍解析了既有应用数据位置，因此这两轮关于“配置、缓存和
运行目录均已隔离”的表述不成立，用户配置文件也不能认定为未被应用启动/退出流程重写。
Modifier 桥的按键、鼠标、滚轮和清除证据不依赖配置内容，轮次 02 的桥资格判定保持
通过；稳定的脱敏证据改为 `E-R02-BRIDGE`。后续 GUI 产品回归必须先通过 Qt test mode
与空缓存的双重隔离门禁。
